# DUO STRIKE 3D — Open-World Tactical FPS (v6.0)

## What's New in v6.0
1. **Fair Combat & No Instant-Death**:
   - Increased player health to **150 HP** with **3 seconds of spawn protection** on deploy and passive health regeneration out of combat.
   - Reduced enemy laser damage to **7 HP** per hit with a **1.15-second lock-on warning** before firing, so you always have time to duck into cover (`C`) or move behind a wall.
   - Enemies are **sector-isolated** with shorter 19–21m detection cones and capped at max 2 active attackers—no more swarming all at once.
2. **Expanded Open World & Stealth Cover**:
   - Expanded map to **320m × 320m** with wider avenues, extra waist-high cover barricades, pillars, and shipping container alleys to walk, hide, and flank.
3. **Deployment Location Selector**:
   - Pick your drop zone on the main screen: **Central Crossroads (Safe Start)**, **Ancient Citadel Fort**, **Harbor Container Port**, or **Remote Mountain Outpost**.
4. **Starter Handgun (Glock-18) & SMG Selector (No Starter Sniper)**:
   - Choose between the **Glock-18 Tactical Pistol** (with 3D slide, reflex sight & two-handed pistol grip) and **Viper MP5 Rapid SMG** right on the main menu or mid-game (`B` / **WEAPONS** button). The Sniper Rifle is now an unlockable high-tier weapon in the Armory.

## How to Run
```bash
npm install
npm run dev
```
